# 📚 Website Perpustakaan

Website Perpustakaan adalah aplikasi berbasis web yang dikembangkan menggunakan **PHP** untuk membantu mengelola data dan aktivitas perpustakaan secara digital.

## ✨ Fitur

* 📖 Pengelolaan data buku
* 👥 Pengelolaan data anggota
* 📚 Pencatatan peminjaman buku
* 🔄 Pencatatan pengembalian buku
* 🗃️ Pengelolaan data perpustakaan

## 🛠️ Teknologi

* PHP
* HTML
* CSS
* MySQL
* XAMPP

## 🎯 Tujuan Project

Project ini dibuat sebagai sarana pembelajaran dalam mengembangkan aplikasi web menggunakan PHP serta menerapkan penggunaan database untuk mengelola data perpustakaan.
